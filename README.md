# Minishell 2

A Unix command line shell interpreter written in C.

## Overview

Recreates a POSIX-compliant shell supporting pipes, I/O redirections, separators (`;`, `&&`, `||`), environment variable management, and built-in commands.

## Getting Started

### Prerequisites
- GCC
- Make

### Build & Run

```bash
# Compile the shell
make

# Start the interactive shell
./mysh
```
